## Phase Goal

ROADMAP goal (verbatim): Between seasons the score keeps moving and reacts to how well each team drafted, without ever rewarding tanking.

<objective>
Vertical slice 1 of 4: a fan-checkable draft-capital-over-slot number for every team and draft. Load the draft data (DATA-06), derive each team's original slots from the prior season's standings, align them to the actual picks, and compute the capped surplus (MODEL-16). Ship it as `fgs draft --season YYYY` and as derived['draft'] for the later plans.

Purpose: this is the metric that rewards trading for picks, not draft position. Getting the slot-1-untraded = 0 acceptance right is what makes "never rewards tanking" true.
Output: `pipeline/src/fgs/draft.py`, `tests/test_draft.py`, DATA-06 checks, CLI wiring.
</objective>

Logic, per research (Claude's discretion on internals):
- `standings(team_games, season)`: REG games of that season only. wp = (wins + 0.5·ties)/games. sos = mean of opponents' REG wp over the team's REG games. grp = stage of the team's last non-REG game ("WC"→1, "DIV"→2, "CON"→3, "SB"→4, SB winner → 5), 0 for no playoffs.
- `original_order`: sort by (grp, wp, sos, franchise_id). Tied groups = same (grp, wp) with grp < 4. Rotate each tied group left by (round_index % len(group)) in later rounds. Prepend `EXPANSION_FIRST = {2002: "HOU"}` to every round of that draft (HOU isn't in the 2001 standings).
- `FORFEITS_R12 = {(2004, 2): ["LV"], (2008, 1): ["NE"], (2012, 2): ["NO"], (2013, 2): ["NO", "CLE"], (2016, 1): ["NE"], (2023, 1): ["MIA"]}`. Before aligning, remove these slots from that round's order and charge each owner `values[min(first_pick_of_round + original_index, 262)]`.
- `align`: edit-distance DP. Match 0, substitute 1, delete slot 3, insert 4. When free_tail is set, trailing insertions after the last slot cost 0. Use free_tail = (round >= 3). Backtrack deterministically (prefer match/sub, then delete, then insert, on cost ties).
- `surplus_table`: per derivable draft year y and round r = 1..7, align. Matched or substituted pairs are regular picks: value goes to orig_value[slot owner] and used_value[actual team]. A deleted slot charges its owner `values[min(last_aligned_pick + 1, 262)]`. Insertions are comp/extra picks, excluded. surplus = used − orig. Every franchise in that draft's original order gets a row, 0 when untouched. Assert max pick ≤ 262.
- `winsor_bounds`, `draft_z`, `decay`, `equiv_pick`, `pick_noun` exactly as in <interfaces>.
