## Phase Goal

ROADMAP goal (verbatim): Between seasons the score keeps moving and reacts to how well each team drafted, without ever rewarding tanking.

<objective>
Vertical slice 3 of 4: let the data decide whether the draft moves the score. Build the training-only walk-forward test of the draft term on the frozen composite and the locked gate (research_revisions), run it once, and record the verdict in `weights.yaml` (`offseason.draft`) and BACKTEST_LOG. Wire the scoring path so a nonzero weight would add `contrib_draft` on weeks 0–3 and zero adds nothing. Build and test both paths with a fake weight.

Purpose: MODEL-16 plus ROADMAP criterion 3: "the draft term's fitted weight is reported, and if it shows no signal it falls back to display-only". Research expects weight 0, but the frozen composite decides.
Output: backtest draft functions + `fgs backtest --draft`, score.load_offseason/apply_offseason, the mood reference guard, the weights.yaml block and the BACKTEST_LOG row.
</objective>
