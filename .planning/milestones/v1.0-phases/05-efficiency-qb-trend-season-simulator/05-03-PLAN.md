  - Per played team-game with pbp (inner join, so the 3 no-pbp games are absent from the sequence, not 0): `adj_epa = net_epa + opp_prior_net`.   - `epa_traj = EWMA_h4(adj_epa) over franchise (crossing seasons) − season-to-date mean of adj_epa (within franchise+season)`.
  - Snapshot = the last per-game row at or before key season*100+week. If that game's season != the snapshot season (week 0 / no in-season game yet) → 0.0. Null → 0.0.
  - Kept as defined even though its Δ ≈ 0 and its sign is negative (research revision). Also log the level-variant Δ.
- qb_trend (MODEL-11; accepted revision A1 = current QB's form LEVEL; RESEARCH Pattern 3):
  - `qb_form` = dropback-weighted EWMA (half_life=4) of qb_epa over the QB's OWN primary-passer games (`over("qb_id")`, any team, any season, playoffs included): `ewm(qb_epa*dropbacks)/ewm(dropbacks)`.
  - `qb_starts` = that QB's primary-passer game count including this game.
  - Per team-game: `qb_new = qb_starts < 2`, and qb_trend = 0.0 if qb_new, else qb_form.
