## Phase Goal

ROADMAP goal (verbatim): The score captures real trajectory (efficiency and QB play) and expectations (preseason expected wins, playoff odds), so "better than your record says" is grounded in evidence.

<objective>
DATA-05: bring nflverse play-by-play into the pipeline. Download each season once, slim it right away, cache it per season, and aggregate it into per-team-game EPA (offense, defense, net) plus the primary QB's dropback EPA and success rate. Wire the pipeline so `fgs build` fills the cache, `fgs refresh` re-pulls only the current season (check first, then write), and `derive(...)` carries the aggregate frame for the factor plans.

Purpose: the epa_traj and qb_trend factors (plan 05-03) need these aggregates. This plan touches no score factor, so the site score stays the same.
Output: `fgs/pbp.py`, tests, CLI wiring, and the cached data (gitignored).
</objective>

Locked decisions (CONTEXT, DATA-05):
- Load with `nflreadpy.load_pbp(season)` one season at a time. Call `update_config(cache_mode="off")` first, the same as ingest.py. Slim right away to SLIM_COLUMNS and cache as `pipeline/data/cache/pbp/{season}.parquet` with an atomic write (temp file + os.replace, like `ingest.save_cache`).
- The garbage-time filter keeps plays with 0.05 <= wp <= 0.95. Exclude kneels, spikes and no_play. CONTEXT says "exclude no-plays", so `play_type == "no_play"` rows are dropped.
- Primary QB = the passer with the most filtered dropbacks per (game, team). Ties go to the lowest id.
- Flag 1999–2000 as `low_confidence`.
- pbp codes are already franchise codes. Assert `codes ⊆ CANONICAL` after `replace(RAW_TO_FRANCHISE)`.

Research facts to honour (RESEARCH "pbp facts", Pattern 1, Anti-Patterns, Pitfall 6):
- QB identity is `coalesce(passer_id, passer_player_id, rusher_player_id when qb_dropback == 1)`. `passer_player_id` is null on scrambles. QB name is `coalesce(passer, passer_player_name)`.
- Spikes have pass=1, so filter `qb_spike` explicitly. Kneels already have pass=rush=0, but filter them too.
- `posteam` can be '' (timeouts). Drop null and ''.
- Treat a null `qb_dropback` as not a dropback (~1.2% of 1999–2000 plays).
- Exactly 3 played games have no pbp: 1999_01_BAL_STL, 2000_03_SD_KC, 2000_06_BUF_MIA. That is KNOWN_NO_PBP. Fail any check on a new gap.
- Expected size: about 1.30M plays → 14,818 team-game rows (7,409 games × 2) as of research. The current season adds rows weekly. ~26 s cold download, ~0.9 MB per season.
