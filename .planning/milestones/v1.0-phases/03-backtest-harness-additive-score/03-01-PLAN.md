Locked decisions used here (from 03-CONTEXT.md; the two "[Revised per 03-RESEARCH ...]" items are binding):
- CONTEXT "Backtest target": target per (season, week, franchise) = mean adjusted margin over the team's next N games in the same season (REG + playoffs), N in {4, 8}, N=8 headline. Adjusted margin = actual margin + (opp pre-game Elo − 1505)/25 − (signed HFA Elo)/25. Opponent + home field ONLY, never the team's own Elo (revised per RESEARCH A1). Snapshots with fewer than 2 remaining games are excluded for that N.
- CONTEXT "Primary metric": Spearman and R² (R² = squared Pearson, per RESEARCH Open Question 6) pooled over test seasons plus per season. Secondary: next-game Brier from a logistic map fit on training seasons only. Buckets: wk0 (week 0), early (1–6), mid (7–12), late (13+, including postseason snapshots).
- CONTEXT "Walk-forward & data splits": for test season S, fit only on seasons < S; first test season 2003. Holdout 2022–2025 is sealed: default test seasons 2003–2021, `--include-holdout` adds 2022–2025. 2026 is never a test season.
- CONTEXT "Baselines": plain Elo, season-to-date REG win %, last-16 win %, season-to-date point differential per game, Vegas spread (Brier only; `spread_line` > 0 = home favored). Output to `pipeline/data/derived/backtest.json`.
- CONTEXT "Additive score": `features.py` builds `elo`, `season_record` (REG win%, ties 0.5, week 0 → 0.5), `last16` (last 16 played games incl. prior seasons, REG+playoffs, ties 0.5) using only games with asof_week <= week.
- Claude's discretion (chosen here): logistic fit = NumPy Newton/IRLS; no scikit-learn/scipy (RESEARCH "Alternatives Considered").
