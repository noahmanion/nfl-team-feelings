2) Create pure `pipeline/src/fgs/explain.py`. Allowed imports: numpy, polars, fgs.mood. No I/O, and never the backtest module. It provides:
- `smooth_map(ref, knots=101) -> (xs, qs)`, with qs = linspace(0,100,knots) and xs = np.quantile(ref, qs/100). This is the unrounded frozen-reference percentile map (per RESEARCH resolved Q1, the smoothed map is used instead of the integer map).
- `slope(c, xs, qs)`, vectorized: (interp(c) − interp(0))/c. Where |c| < 1e-6, use the derivative at 0 from the knot pair straddling 0. If those two knots coincide, step outward until xs differ, so the result is always finite and > 0.
- `largest_remainder(real: np.ndarray, total: int) -> np.ndarray[int64]`. First spread the residual (total − Σreal) proportionally to |real|, or evenly if Σ|real| == 0. Then floor, and add +1 to the k largest fractional parts using a stable argsort, so ties resolve in factor order. Output sums exactly to total and is deterministic.
- `baseline(ref) -> int`, equal to int(mood.percentile_scores(np.array([0.0]), ref)[0]). Never hard-code 50 or 49.
- `add_points(scored: pl.DataFrame, factor_keys: list[str], ref: np.ndarray) -> pl.DataFrame` adds Int64 `pts_{f}` for each factor. Per row: T = score − baseline; real_f = contrib_f (UNROUNDED column, Pitfall 8) × slope(composite); pts = largest_remainder(real, T). Vectorize the slope and keep a per-row numpy loop only for the integer reconciliation.
- `PHRASES` (fact phrases) keyed by (factor, "hi"/"lo") → (strong, mild), for ALL SEVEN planned factors: elo, season_record, last16, mov, sow, streak, luck. Use the RESEARCH Pattern 4 wording. That includes sow "have a record that runs ahead of their margins" / "lags behind their margins", which is the wording for the expected negative fitted sign. 04-03 re-checks it once the sign is known. Templates: {rec} = "W-L" or "W-L-T", {k} = |int(raw streak)|.
- `FADE = {"hi": " (that tends to fade)", "lo": " (that tends to even out)"}`. Append FADE[direction] when sign(points) ≠ direction. This is what makes negative-weight factors read honestly.
- Tiers: strong when |points| ≥ 20 for elo (Elo dominates, Pitfall 5), and |points| ≥ 10 for every other factor. Otherwise mild.
- `blurb(row: dict, factor_keys, nick: str, week: int) -> str`. direction = "hi" if z_f > 0, "lo" if z_f < 0. Candidates exclude: points == 0, z == 0, season_record at week 0, streak with |raw| < 2 (Pitfall 6), and any factor missing from PHRASES. Take the top 2 by |points| (ties go to factor_keys order). Sentence: "The {nick} {p1}, {and|but} {p2}." using "but" iff the two points signs differ. One candidate gives "The {nick} {p1}." None gives "The {nick} are about as average as it gets right now." Week 0 prefixes "Preseason, carrying last season's form: " and lower-cases "The" to "the". Always ends with "." Plural verbs ("are"/"have"), per RESEARCH A2.
