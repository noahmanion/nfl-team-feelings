## Phase Goal

**As an** NFL fan, **I want to** open a local site and see how every fanbase should feel right now (Elo-only for now), refreshed by a single command after each week, **so that** I can tell whether my team is really as good or as bad as it feels.

<objective>
Thinnest real end-to-end slice: Elo snapshots → percentile score + mood bands with hysteresis → the full JSON contract in web/public/data/ → a Vite + Svelte 5 page that renders the latest week's ranked mood board.

Purpose: After this plan a user can run `npm run dev` and see all 32 teams ranked with record, score, mood label and weekly change (SITE-01). Every later plan only thickens this slice (scrubbing/deep links, refresh/partial week, states/polish).
Output: mood.py, export.py, asof.py, `fgs export`, committed JSON, the web/ app with the board.
</objective>

Decision key for Phase 2 (CONTEXT.md has no IDs; these IDs are used by all 02-* plans):
- D-01 Displayed score = integer 0–100 percentile of the team's current rating among ALL historical team-week snapshots 1999→now (week-0 + regular-season rows). Underlying rating = Elo in Phase 2.
- D-02 No decimals in the UI; Elo only as a secondary detail.
- D-03 Seven bands (≥95 Planning the parade · 80–94 Buying the jersey · 60–79 Cautiously smug · 40–59 It’s fine. Everything’s fine. · 20–39 Checking the draft order · 5–19 Refreshing mock drafts · <5 Witness protection), labels + emoji in pipeline config, emitted in meta.json; frontend never hardcodes them.
- D-04 Hysteresis: label changes only when the score is past the band boundary by ≥2; computed chronologically per team-season; week 0 starts fresh.
- D-05 score_delta vs the team's previous snapshot week in the same season (null at week 0 → "–"); rank_delta = previous rank − current rank (positive = moved up).
- D-06 JSON contract written by `fgs export` into web/public/data/: meta.json, latest.json, snapshots/{season}.json, teams/{ABBR}.json, history.json, callouts.json ([]). The only pipeline↔site interface.
- D-07 Team display metadata from nflreadpy.load_teams() mapped to canonical franchise ids; color chips, never logos.
- D-08 Generated JSON is committed (site runs without Python).
- D-09 `uv run fgs refresh` = re-download → build → check (abort on failure) → export; latest week = latest week with ≥1 played game, partial_week when that week has unplayed games; site shows "In progress".
- D-10 Site shows "Last updated" from meta.generated_at and "Data through {date}".
- D-11 web/ = Vite 8 + Svelte 5 + TypeScript ~6.0 (svelte-ts template), Node 22 via web/.nvmrc, tiny hash router (#/ and #/board/{season}/{week}), no router lib, no Observable Plot this phase.
- D-12 Start locally: `cd web && npm install && npm run dev`.
- D-13 Single ranked list: rank, color chip + abbr + name, record W-L(-T), big score, mood label + emoji, ▲/▼/– delta. Phone-first, no horizontal scroll at 375px; wider table-like row on desktop.
- D-14 Scrubber: season select + week range slider (Preseason / Week N / Wild Card / Divisional / Conference Championships / Super Bowl) + "Latest" button; changes update the hash.
- D-15 Neutral base + one accent; playful copy only in labels/emoji/headline; light + dark via prefers-color-scheme.
- D-16 Root README: idea, how to run (pipeline refresh + site dev), status. Brief.
- D-17 Headline "How should you feel about your team?"; postseason week labels derived from game_type, not raw week numbers.
