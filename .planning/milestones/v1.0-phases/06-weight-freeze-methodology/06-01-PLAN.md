  <action>
Create `pipeline/src/fgs/bootstrap.py`. It is pure NumPy and imports nothing from `fgs`. The caller passes stat functions, so the module stays reusable and keeps no leakage surface. Put the constants and signatures below in the module docstring as well.
- Constants: `B_DEFAULT = 2000`, `SEED = 20221`, `LEVEL = 0.95`.
- `season_blocks(season: np.ndarray) -> list[np.ndarray]`: one index array per unique season, in sorted order.
- `stratified_clusters(season: np.ndarray, cluster_key: np.ndarray) -> list[list[np.ndarray]]`: per season, the row-index arrays of each unique cluster key. Team-season = franchise_id; season-week = asof week. Any hashable/str array works.
- `draw_blocks(rng, blocks) -> np.ndarray`: `len(blocks)` blocks drawn with replacement, concatenated.
- `draw_stratified(rng, strata) -> np.ndarray`: within each season, draw that season's clusters with replacement (same count), then concatenate.
- `distinct_block_resamples(k: int) -> int`: `math.comb(2k − 1, k)`.
- `percentile_ci(values, level=LEVEL) -> list[float] | None`: nan-aware 2.5/97.5 percentiles as plain floats. Returns None if there are no finite values.
- `paired_bootstrap(stat_fns: dict[str, Callable[[np.ndarray], float | None]], draw: Callable[[np.random.Generator], np.ndarray], *, diffs: dict[str, tuple[str, str]] | None = None, B: int = B_DEFAULT, seed: int = SEED) -> dict`:
  - one rng from `np.random.default_rng(seed)`
  - per draw, ONE index array shared by every stat (that is what makes it paired); None → NaN
  - returns `{"B", "seed", "stats": {name: {"ci": [lo, hi], "sd": float, "n_finite": int}}, "diffs": {name: {"ci": [lo, hi], "sd": float, "n_finite": int}}}`, where each diff is `vals[a] − vals[b]` per draw
  - floats are rounded to 6 dp with NaN → None (strict JSON; same convention as `backtest._clean`)

Tests in `pipeline/tests/test_bootstrap.py`, synthetic only. They cover every behavior bullet. For Spearman inside tests, use `fgs.backtest.spearman` on index-selected arrays; the test is allowed to import backtest. Use B=300 in tests for speed, except the determinism test (B=200 twice).
