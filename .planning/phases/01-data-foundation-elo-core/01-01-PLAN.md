## Phase Goal

**As a** project owner building the feel-good score, **I want to** run one command and see every NFL franchise's Elo rating and record as of any week since 1999, **so that** every later score is built on clean, chronologically replayed, trustworthy data.

<objective>
Walking Skeleton: the thinnest real end-to-end path, nflreadpy → own parquet cache → franchise normalization → games/team_games → 538-style Elo replay → (season, week, franchise) snapshot grid → `fgs elo` ranked table. All real data, all real math. Plans 02 and 03 thicken it with era-rule data checks and snapshot/CLI hardening.

Purpose: prove the whole pipeline works before any check or polish is layered on.
Output: `pipeline/` uv project, `fgs` CLI with `ingest`, `build`, `elo`; derived parquet files; unit tests that pin the Elo math; README run section. SKELETON.md (already written in the phase dir) records the architecture.
</objective>

- D-14 K=20, MOV multiplier `ln(max(|MOV|,1)+1) × 2.2 / (winner_elo_diff × 0.001 + 2.2)`
- D-15 era HFA lookup 65 (1999–2009), 58 (2010–2019), 30 (2020), 45 (2021+); winner_elo_diff includes HFA; ties use denominator 1.0 (multiplier = ln(2)×2.2)
- D-16 regress 1/3 toward 1505 at each season boundary; week 0 = post-regression rating
- D-17 zero-sum per game (test invariant)
- D-18 snapshot W-L-T counts REG games only
- D-19 regress all teams eagerly at the season boundary
- D-20 `fgs elo` beyond latest played week errors non-zero; latest week derived from cached data
- D-21 own parquet cache, not nflreadpy's cache
- D-22 BUF and CIN 2022 have 16 REG games (data-check exception)
- D-23 grid keyed (season, week, franchise_id), week 0 → last played week, forward-filled over byes
- D-24 current week = latest played game in cached data
