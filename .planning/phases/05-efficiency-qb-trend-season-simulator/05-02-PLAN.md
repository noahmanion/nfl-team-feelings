Locked decisions (CONTEXT MODEL-13, plus accepted research revision A2):
- Vectorized NumPy Monte Carlo per (season, week). It simulates every REG game not known as of the week (known = `played & asof_week <= week`) using as-of Elo win probabilities `1/(1+10^(-diff/400))` with era HFA (`hfa_for(season)`; 0 if neutral). Ratings are fixed within a run (no hot updates).
- A2: once per sim, draw a per-team rating offset `N(0, SIGMA=100 Elo)` and add it to every game that team plays in that sim. Ratings stay fixed within a sim.
- Era rules come from `season_config`: `divisions(season)`, `playoff_teams(season)`, `reg_games(season)`. Division winner: win% → head-to-head win% among the tied set (0.5 if they never met) → division win% → random. Wildcards are chosen one at a time per conference: win% → head-to-head → random. Rank by win%, not wins (BUF/CIN 2022 played 16).
- Default 2,000 sims. RNG = `np.random.default_rng([seed, season, week])`, one stream per snapshot, so results don't depend on computation order or on incremental runs.
- Outputs per (season, week, franchise): `playoff_prob`, `exp_wins` (expected final REG wins, ties 0.5). Week 0 = preseason.
- Cache: `{cache_dir}/{model_version}.parquet` keyed by (season, week, franchise_id). `model_version` = the first 12 hex chars of sha256 over canonical JSON of {Elo params (dataclasses.asdict(EloParams())), HFA_BY_ERA, both DIVISIONS tables, playoff_teams per season 1999..2030, n_sims, sigma, seed, SIM_VERSION}. Each row carries a per-season `input_digest`: sha256 over that season's REG (game_id, home_id, away_id, result, played, asof_week, neutral), sorted by game_id, plus snapshot (week, franchise_id, round(elo, 9)), sorted. Recompute exactly the seasons whose digest changed or are missing (RESEARCH Pattern 6).
- Expectations (MODEL-08 locked): nflverse `win_totals` 2003–2020 where available (tag `vegas`), else the model's week-0 sim exp_wins (tag `model`). No hand-entered 2021+ totals (deferred, v2). Lines are normalized per season (A3): `vegas_norm = line - mean(line over season) + reg_games(season)/2`.

Expected real-data numbers (RESEARCH Simulator + vs_exp tables): ~15 ms per snapshot, under ~15 s for all 1999–2026 snapshots. Σp − spots max ~1e-14. Σexp_wins − REG games max ~4e-6 (float32). End-of-REG slot accuracy ≈ 98%. r(model wk-0 exp_wins, Vegas line) = 0.863 pooled 2003–2020 (per season 0.72–0.93). win_totals: 576 rows, `season,team,line,over_odds,under_odds`, legacy codes OAK/SD/STL.
