## Phase Goal

**As an** NFL fan, **I want to** open a local site and see how every fanbase should feel right now (Elo-only for now), refreshed by a single command after each week, **so that** I can tell whether my team is really as good or as bad as it feels.

<objective>
Thicken the board slice with time travel: a season select + week slider + Latest button that scrub the board to any season/week since 1999, driven by a tiny hash router so every view has a deep link that reopens it.

Purpose: SITE-04 (scrub any week) and the deep-link part of SITE-10.
Output: router.ts (+tests), route.svelte.ts, tickLabel, loadSeason with cache, Scrubber, StatusPanel (notice variant), App routing.
</objective>
