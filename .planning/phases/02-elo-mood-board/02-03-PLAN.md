## Phase Goal

**As an** NFL fan, **I want to** open a local site and see how every fanbase should feel right now (Elo-only for now), refreshed by a single command after each week, **so that** I can tell whether my team is really as good or as bad as it feels.

<objective>
Make the weekly loop one command: `uv run fgs refresh` downloads fresh nflverse data, checks it, and regenerates every JSON file the site reads, safely (nothing is written on failure) and correctly on a partially played week. Then document how to run the whole thing.

Purpose: PIPE-01 (one-command refresh, tested on a partial week) and PIPE-03 (single-command local site + README).
Output: `fgs refresh`, refresh-abort and partial-week tests, freshly regenerated web/public/data, updated README.
</objective>
